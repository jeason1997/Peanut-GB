# V3s PC 串口控制台

Windows 双击同目录 `v3s_control.cmd`。需要 Python 3、Tkinter 和 pyserial；当前开发机已经具备。
其他机器缺依赖时执行 `python -m pip install pyserial`。

默认 COM15、115200、8N1，无软/硬件流控。点击“连接”即可；串口只能由一个工具占用，
连接前关闭其他串口监视器。打开串口时 DTR/RTS 保持关闭，不发送复位、登录或启动命令。

- 下方输入框输入 Linux 命令，Enter 发送（以 CR 结束）。Ctrl+C 按钮发送中断字符。
- 鼠标按住游戏按钮即可持续控制。
- 勾选“启用键盘控制”后，点击游戏面板空白处或窗口空白处获取焦点。
  方向键控制移动，Z=A、X=B、Enter=Start、Backspace=Select。
  输入框内仍然正常打字，不触发游戏按键。
- “退出游戏 Q”发送 q，让当前 Peanut GBC 前端退出并恢复设备屏幕终端。
  断开串口或关闭PC工具本身不会发送退出游戏命令。

游戏控制适配当前 `frontend_fb.c`：WASD/Z/X/E/R，每字符保持8显示帧。
工具按住时每90ms重发，松开后最迟约134ms停止（模拟器掉帧时可能更长）。
设备现有协议只保留最后一个按键，无法同时按住方向+A/B；工具未更改设备协议。
切换到其他窗口、关闭键盘控制或断开连接会清除按住状态。

输出区域是日志式终端，会去掉ANSI颜色/控制序列；不支持vim、top等全屏终端程序。
游戏控制需要模拟器已经在设备上运行；工具不会自动部署ROM、覆盖存档或执行远程命令。

也可命令行启动：

```powershell
python extensions/tools/v3s_control.py --port COM15 --baud 115200 --connect
```

实机验证：Tk界面生命周期、COM15打开/关闭、后台串口收取及连续方向控制均通过。
